GREEN VIEW - deploy steps
1. Upload this whole folder (unzipped) to Netlify Drop, Cloudflare Pages or GitHub Pages (HTTPS required).
2. Open the URL in Safari on the iPhone > Share > Add to Home Screen.
3. Use ONLY the Home Screen icon from then on (Safari tab and installed app have separate storage).
4. Test offline: open once online, enable airplane mode, fully close, reopen.
5. Back up regularly from Settings and copy the backup somewhere safe.
If you edit index.html, change greenview-v2 to greenview-v2 in sw.js.
